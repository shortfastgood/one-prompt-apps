# NIGHT PATROL

A self-contained 3D night flight-combat game, written from scratch in JavaScript and WebGL. No libraries, installation, build step, CDN, fonts, images, or network access are required. All aircraft, terrain, sky, effects, and audio are generated by the game.

## Play

Open **index.html** in a current browser with WebGL enabled. It works directly from disk. Alternatively, serve this directory:

```sh
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

Choose a Falcon multirole fighter, Kite propeller fighter, or Scythe rocket interceptor and press **Launch sortie**.

| Control | Action |
| --- | --- |
| Mouse movement | Steer; center the mouse to fly straight |
| W / S or up / down | Pitch up / down |
| A / D or left / right | Bank and turn |
| Q / E | Decrease / increase throttle |
| **Shift** | Burn booster reserve (Scythe interceptor only) |
| Space or left mouse button | Fire cannons |
| Escape | Pause / resume |
| Touch stick and FIRE | Touch controls |

Keyboard steering takes over from mouse steering until the mouse moves again. Pausing or leaving the window releases all controls. Touch flight uses the initial 72% throttle.

## Flight and combat

The flight model is an accessible approximation, not an engineering simulator. Aircraft names evoke their real-world roles; displayed values define the game's tuned flight envelopes, rather than certified real-aircraft specifications.

- Aircraft have enforced speed, acceleration, turn, climb, stall, ceiling, armor, damage, and cannon temperature limits. Turn-rate bars describe performance at 65% of top speed. High speed widens turns; climbs consume airspeed; low speed causes a stall and descent.
- Enemy planes maneuver, lead targets, and fire visible red-orange projectiles. Player rounds leave gold traces. Swept projectile collision checks apply real damage to either side. A small forward aiming assist helps lead targets inside the gunsight.
- Cannon ammunition is unlimited; sustained fire overheats the weapon until it cools. Short bursts are more effective.
- The first wave contains three hostiles. Subsequent waves increase the number (up to twelve), armor, maneuvering, firing frequency, and damage. Clearing a wave repairs the player and starts the next wave after four seconds.
- Ground and aircraft collisions cause damage. At zero health the player's controls fail, the aircraft tumbles and falls, and ground impact triggers exactly two seconds of black screen before returning to the hangar. Flight and blackout timers stop progressing while the browser is suspended.
- The radar and edge indicators locate offscreen opponents. A soft boundary turns aircraft back toward the island chain.
- The sky is a seeded star field lit by a low moon. Damaged aircraft shed smoke, then fire, before exploding.

## Aircraft

- **Falcon F-16** — multirole fighter. Fast and light; the all-rounder.
- **Kite P-51** — propeller fighter. Slow but the tightest turn.
- **Scythe R-77** — rocket-powered interceptor. Highest climb and high top speed, but a short booster reserve caps sustained speed and it turns least. **Shift** burns the reserve; overheat cuts it.

## Deviations from the reference

This build adopts the proven core of `apps/flight-combat/by-codex-gpt-6/` (flight math and the deterministic simulation) and layers new visuals, audio, and tests on top:

- **Namespacing** — `Airframe3D`→`NyxPatrol`, `FlightSim`→`NyxSim`, `window.airframeStatus`→`window.nyxStatus`; brand retitled to **Night Patrol / OPERATION OVERNIGHT SQUADRON**.
- **New third aircraft** — the rocket interceptor with a booster reserve (`boost`), overheat-limited top speed, and a dedicated Shift / touch-booster input.
- **Night lighting** — a Blinn-Phong fragment shader with a moonlight `uSun`, cool ambient, and a low warm-to-cool night grade; a seeded star dome and moon disc drawn additively behind the scene.
- **Tracer glow** — additive `drawGlow` makes friendly (gold) and enemy (red-orange) rounds read as light against the dark.
- **Wounded state** — a one-shot deterministic `wounded` event fires when any plane drops below 45% hull, driving a smoke-then-fire particle progression distinct from explosion bursts.
- **Audio** — a speed-tracked sawtooth engine hum plus fire/explosion SFX.

## Source

- `index.html`, `style.css`: hangar, selection, controls, instruments, responsive layout.
- `engine.js`: WebGL shaders (night lighting), camera, matrices, mesh generation, star dome, aircraft models.
- `simulation.js`: independent flight physics, AI, projectiles, damage, wounded state, waves, loss state machine.
- `game.js`: scene, terrain, input (incl. booster), HUD, particles, synthesized audio.
- `simulation.test.cjs`: executable behavioral tests for the simulation.
- `engine.test.cjs`: camera, orientation, geometry, and local-asset checks. These do not replace visual GPU testing.
- `night-patrol.realtime.cjs`: headless end-to-end smoke test (see below).

Run the behavioral and engine checks with Node.js:

```sh
node --test simulation.test.cjs engine.test.cjs
```

Run the headless end-to-end smoke test (drives a real browser via the locally-installed
`playwright-cli`, initializes WebGL, launches the interceptor, fires, and asserts zero
external network requests):

```sh
node night-patrol.realtime.cjs
```

The game has no persistent data or backend. Reloading resets the sortie.

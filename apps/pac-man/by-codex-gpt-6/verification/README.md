# Pac-Man verification

Run from the repository root with Node.js 24 or newer:

```sh
node apps/pac-man/by-codex-gpt-6/verification/run.cjs
```

The deterministic tests require only Node. Real-browser tests run automatically when Playwright and a launchable Chromium or Google Chrome are available; otherwise they report a skip with the reason. The runner fails on a test failure, a 30-second per-file timeout, or game-script line/branch/function coverage below 100%. It creates `coverage/lcov.info` for coverage viewers.

## Implementation

- `harness.cjs` extracts the actual inline script from `../index.html` unchanged and evaluates it in isolated VM contexts. `game.generated.js` is an ignored, regenerated coverage artifact; never edit it.
- `logic.test.cjs` tests game rules with controlled random values, explicit fixtures, and 20 recorded maze seeds. Connectivity assertions use an independent traversal.
- `browser-boundaries.test.cjs` tests registered events, RAF timing, and Canvas commands using browser-boundary mocks. It also checks static offline prerequisites.
- `real-browser.test.cjs` opens the actual HTML offline in a headless browser and checks rendered pixels, responsive layout, keyboard events/repeats, restart, and Escape. One check uses native RAF; input scenarios use Playwright clock control and explicit game-state fixtures.
- `browser-support.cjs` tries bundled Chromium, then installed Chrome. Missing packages, unusable browsers, or missing clock support produce explicit skips. Assertions after successful setup fail normally; they are never converted into skips. `browser-support.test.cjs` checks missing support and fallback behavior without uninstalling anything.
- Test titles contain verification-prompt path IDs. `PATHS.md` maps every ID to its tests.

Only the extracted game script is included in coverage. The test-only state bridge, fixtures, and mocks are excluded. Source lines in LCOV refer to `game.generated.js`; for this HTML, add 15 to locate the corresponding HTML line. The extracted artifact always contains the current source, so use that artifact if the HTML structure changes.

## Verified result — 2026-10-08

Node.js v24.21.0 with Playwright 1.64.0: **70 tests passed, 0 failed, 0 skipped**, approximately 1.63 seconds for the final run. This includes four browser subtests. A sandboxed run also verified the unavailable-browser path: **65 passed, 1 skipped, 0 failed**. The browser passed when launched outside that sandbox. Game-script coverage: **100% lines, 100% V8 branches, 100% functions**; no uncovered lines reported. No game source changes were necessary.

These are Node/V8 coverage metrics. Node does not report a separate statement-coverage percentage; 100% line coverage should not be presented as measured 100% statement coverage. The path assertions supplement execution coverage but cannot prove every possible event sequence or random maze.

All 77 prompt IDs have test mappings. D08 now passes real-browser offline loading, sampled Canvas pixels, responsive sizing, and console/network checks. Keyboard repeat events are generated by repeated Playwright `keyboard.down` calls; this checks browser event handling but does not measure physical OS key-repeat timing. Native background-tab transitions remain outside this smoke suite; their logic is covered by the deterministic visibility-handler tests. Browser execution is supplemental and is not included in the Node/V8 coverage percentage.

Some cases deliberately construct defensive states (e.g. a player at the boundary or isolated ghost destinations); they are labeled by their assertions and do not expand the gameplay contract. Direction arguments use the game's canonical direction arrays, matching keyboard input.

## Optional browser installation

From this directory (or the repository package root):

```sh
npm install --save-dev playwright
npx playwright install chromium
```

Alternatively install Google Chrome with `brew install --cask google-chrome`; the Playwright npm package is still required. Nothing is installed automatically by the tests. Playwright 1.45 or newer is required for clock control.

Run just the optional browser check:

```sh
node --test apps/pac-man/by-codex-gpt-6/verification/real-browser.test.cjs
```

Run that command from the repository root. A browser-launch skip can also indicate operating-system or sandbox restrictions, even when a browser is installed. Check the reported reason and run in an environment that permits browser subprocesses. Skipped checks are not evidence of browser verification.
